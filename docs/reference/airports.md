# 2011 airport data

2011 airport data

## Usage

``` r
airports
```

## Format

A data frame with 221 rows and 8 variables:

- iata:

  Character vector

- airport:

  Character vector

- city:

  Character vector

- state:

  Character vector

- country:

  Character vector

- lat:

  Numeric vector

- long:

  Numeric vector

- cnt:

  Integer vector
